# PR note — comment UX upgrade (visuals modes)

## Audit findings (Step 1)

- **Renderer**: `packages/reporters/src/markdown/render.ts` (state machine over
  coverage-report.json). **SVG/badges**: `packages/history` (sparklines, delta
  badges, shields endpoints — and now the composite metric band). **Store**:
  `packages/action/src/baseline/` (orphan `coverage-baseline` branch + index).
  **Posting**: `packages/action/src/github.ts` (in-place upsert, D5 marker) +
  `postCoverageReport.ts` (check run + annotations).
- **Why the trend rendered as "black bars"**: no images were ever embedded —
  the action never committed `badges/` to the baseline branch, and the comment
  never referenced raw URLs. The "black bars" are the unicode block glyphs
  (`▁▂▅█`) in the totals Trend column, which render as solid bars in some
  fonts. Additionally, had raw URLs been used on a private repo they would
  break anyway: GitHub's camo proxy cannot fetch authenticated raw URLs.

## What changed (Step 2)

1. Composite metric-band SVG (`packages/history/src/metricBand.ts`): all four
   metric cards (value, ▲▼ delta, 30-run sparkline, green/gray/red) in one
   deterministic SVG, light + dark variants, committed to the baseline branch
   as `badges/metric-band-{light,dark}.svg` on every baseline publish (same
   commit as the entry), embedded via `<picture>` with `prefers-color-scheme`.
2. Mermaid `xychart-beta` trend block (native rendering, private-repo safe).
3. `[!NOTE]/[!WARNING]/[!CAUTION]/[!IMPORTANT]` alerts for verdict/severity.
4. Tables: 🟢🟡🔴 status, ▲▼ arrows, bold violating rows — no HTML styling.
5. Config `visuals: images | mermaid | text | auto` (default auto): auto
   detects visibility via `repos.get`; private → mermaid + unicode (no raw
   URLs, fixing the broken-image class of bugs); public → images + mermaid.
6. All 8 states, D5 marker, verdict line 1, changed-files-first and 65k
   truncation preserved (206 tests, snapshots per visuals mode).

Schema: no new report fields — `visuals` is config-only; schemaVersion stays 1.
